# 完整流程（清理 + 迁移）

> 适用于：有其他盘且空间充足的情况。

## 流程总览

```
公共步骤（flow-common.md）          本文件独有
┌──────────────────────┐
│ 第一步：全面扫描      │
│ 第二步：生成报告并展示 │
│ 第三步：清理临时文件   │
│                      │   ┌─────────────────────┐
│                      │──▶│ 迁移阶段（见下文）    │
│                      │   └─────────────────────┘
│ 第四步：清理应用缓存   │
│ 第五步：验证并报告     │
│ 第六步：补充建议       │
└──────────────────────┘
```

先执行 `flow-common.md` 的第一步到第三步，然后执行本文件的**迁移阶段**，再继续 `flow-common.md` 的第四步到第六步。

## 迁移阶段

在清理临时文件之后、清理应用缓存之前插入此阶段。

### 前置条件

**迁移前必须通过 6 项前置检查**（云同步检测、重定向检测、已有 junction 检测、BitLocker 检查、NTFS 文件系统检查、空间检查）：

> 详细前置检查和 10 步迁移操作命令：参阅 `migration-guide.md`
> 安全规则细则（云同步/UWP/加密/游戏/开发者）：参阅 `safety-rules.md`

### 核心原则

**复制 → 验证完整性（数量+大小必须一致） → rename 备份 → 创建 junction → 测试 → 删备份**
